写文章只需要会一点 Markdown——一种用普通文本表达格式的写法。下面是最常用的几种，照着用即可。

## 标题

在文字前面加 `#`，一个 `#` 是一级标题，两个是二级，最多到六级：

```markdown
# 一级标题
## 二级标题
### 三级标题
```

## 正文与强调

直接写就是正文段落。想**加粗**就在文字两边各加两个星号，想*斜体*就各加一个：

```markdown
这是**加粗**，这是*斜体*，这是`行内代码`。
```

## 列表

无序列表用 `-` 开头，有序列表用 `1.` 开头：

```markdown
- 第一件事
- 第二件事

1. 第一步
2. 第二步
```

## 链接与图片

```markdown
[链接文字](https://example.com)
![图片说明](图片地址)
```

## 引用与分割线

段落开头加 `>` 就是引用，单独一行三个 `---` 是分割线：

```markdown
> 这是引用。

---
```

## 代码块

用三个反引号包起来，还可以在开头注明语言：

````markdown
```python
print("Hello, world!")
```
````

## 表格

```markdown
| 语法 | 作用 |
| ---- | ---- |
| `**` | 加粗 |
| `*`  | 斜体 |
```

掌握这些就足够开始写了。多写几篇之后，你会自然想尝试更多花样的。
