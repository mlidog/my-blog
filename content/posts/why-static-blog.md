想拥有一个自己的博客，其实有很多条路可以走。我最后选择了「静态博客 + GitHub 托管」，理由有三点。

## 速度快，还免费

静态博客没有后台程序，打开网页就是一堆已经做好的 HTML 文件，加载特别快。托管在 GitHub Pages 上不花一分钱，对于一个刚开始写博客的人来说，这是很好的起点。

## 内容完全属于自己

所有文章都是普通文本文件，放在自己的仓库里。不用担心平台改规则、删内容，换地方也很容易——把文件夹带走就行。

## 顺便学会了前端

这也是最重要的一点。搭建和维护这个博客的过程中，会自然地接触到 HTML、CSS 和 Markdown：

1. 改样式练 CSS；
2. 改页面结构练 HTML；
3. 写文章练 Markdown。

博客既是作品，也是练习场。这可能就是它最大的价值。
