Markdown 写作小抄

2026年8月13日 · 1 分钟阅读 · 教程Markdown

写文章只需要会一点 Markdown——一种用普通文本表达格式的写法。下面是最常用的几种，照着用即可。

标题

在文字前面加 #，一个 # 是一级标题，两个是二级，最多到六级：

# 一级标题
## 二级标题
### 三级标题

正文与强调

直接写就是正文段落。想加粗就在文字两边各加两个星号，想斜体就各加一个：

这是**加粗**，这是*斜体*，这是`行内代码`。

列表

无序列表用 - 开头，有序列表用 1. 开头：

- 第一件事
- 第二件事

1. 第一步
2. 第二步

链接与图片

[链接文字](https://example.com)
![图片说明](图片地址)

引用与分割线

段落开头加 > 就是引用，单独一行三个 --- 是分割线：

> 这是引用。

---

代码块

用三个反引号包起来，还可以在开头注明语言：

```python
print("Hello, world!")
```

表格

| 语法 | 作用 |
| ---- | ---- |
| `**` | 加粗 |
| `*`  | 斜体 |

掌握这些就足够开始写了。多写几篇之后，你会自然想尝试更多花样的。
